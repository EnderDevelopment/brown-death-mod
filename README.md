# Brown Death Mod

Instant death on brown blocks in Minecraft

## Features

- Instant death when interacting with brown blocks (wool, concrete, terracotta, stained glass)
- Instant death when breaking brown blocks

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/brown-death-mod/releases)
2. Place the mod file in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

- Simply interact with or break any brown block to trigger instant death

## Configuration

No additional configuration is required. The mod works out of the box.
